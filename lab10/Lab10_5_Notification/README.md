# Lab 10.5 – Local Notifications (MANDATORY – LO7)

## 1. Mô tả
Tích hợp thông báo cục bộ (`flutter_local_notifications`) đáp ứng chuẩn đầu ra LO7.
Hỗ trợ xin quyền `POST_NOTIFICATIONS` trên Android 13+ và kích hoạt thông báo tức thì lên khay hệ thống.

## 2. Cách chạy ứng dụng
```bash
flutter pub get
flutter run
```
